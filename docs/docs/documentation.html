Installation

  1. Clone repository and enter project directory.
  2. Create and activate virtual environment.
  3. Install dependencies from requirements file.

A model loads only into the grid size and package count it was trained on. Each START writes to a new folder under runs/, so a run never overwrites an earlier model.

Command-Line Training

{% include code-block.html code="python train_agent.py" %}
  • Trains DQN for 100,000 timesteps by default (--timesteps).
  • Saves the model as runs/<run>/model.zip, with its replay buffer next to it.
  • Generates runs/<run>/training_progress.png.
  • Tests the agent on 3 episodes, on the configuration it was trained on.

Options: --timesteps, --seed, --grid-size, --packages, --max-steps, --step-cost, --checkpoint-freq, --runs-dir.

Environment Details

Action Space

ActionDescription
0Move up
1Move down
2Move left
3Move right
4Pick up package
5Drop off package

Observation Space

For one package: six dimensions (agent x/y, carrying status, package x/y, delivered status). Additional packages append three dimensions each.

Reward Structure

  • +10 deliver package
  • +1 pick up package
  • +0.1 per step reducing nearest-package distance
  • -0.01 multiplied by nearest package distance
  • -0.05 per step as baseline movement penalty
