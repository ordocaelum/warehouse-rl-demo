Installation

  1. Clone repository and enter project directory.
  2. Create and activate virtual environment.
  3. Install dependencies from requirements file.
{% include code-block.html code="git clone https://github.com/ordocaelum/warehouse-rl-demo.git cd warehouse-rl-demo python -m venv venv source venv/bin/activate pip install -r requirements.txt" %}

Environment Details

Action Space

ActionDescription
0Move up
1Move down
2Move left
3Move right
4Pick up package
5Drop off package

Observation Space

For one package: six dimensions (agent x/y, carrying status, package x/y, delivered status). Additional packages append three dimensions each.

Reward Structure

  • +10 deliver package
  • +1 pick up package
  • +0.1 per step reducing nearest-package distance
  • -0.01 multiplied by nearest package distance
  • -0.05 per step as baseline movement penalty
