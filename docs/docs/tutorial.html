Expected Results and Learning Curves

As environment complexity rises, absolute average reward declines while policy quality can still improve. Focus on moving-average trend direction instead of raw single-episode values.

Signal to track: 50-episode moving average should rise or stabilize at each stage before progression.

Checkpoint Milestones

  • Stage 1 complete when average reward exceeds +6 consistently.
  • Stage 2 complete when degradation stops and two-package deliveries occur.
  • Stage 3 complete when moving average trends upward despite noise.
  • Stage 4 complete when reward variance narrows and delivery frequency increases.
