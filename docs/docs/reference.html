Observation Space

Observation vector format:

{% include code-block.html code="[agent_x, agent_y, carrying, package_1_x, package_1_y, package_1_delivered, ...]" %}

Each additional package contributes three fields: x coordinate, y coordinate, delivered flag.

Reward Structure

  • Delivery bonus: +10
  • Pickup reward: +1
  • Distance reduction bonus: +0.1
  • Distance penalty: -0.01 multiplied by nearest package distance
  • Step cost: -0.05 default

DQN Parameters

ParameterDefaultNotes
Learning rate1e-3Primary optimization sensitivity control
Replay buffer10kIncrease for larger environments
Initial epsilon1.0Full exploration at start
Final epsilon0.1Residual exploration after decay
Total timesteps100kScale with complexity

Environment Details

  • Grid-world delivery environment with configurable dimensions and package count.
  • Delivery zone fixed to bottom-right corner by default.
  • Episode termination controlled by delivery completion or max steps.
  • Dashboard and visualizer provide real-time trajectory and reward diagnostics.
