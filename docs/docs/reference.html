Observation Space

Observation vector format:

{% include code-block.html code="[agent_x, agent_y, carrying, package_1_x, package_1_y, package_1_delivered, ...]" %}

Each additional package contributes three fields: x coordinate, y coordinate, delivered flag. A package's x/y is where it currently is: its pickup cell while waiting, the agent's cell while carried, the delivery zone once delivered.

Bounds are exact: coordinates lie in [0, grid_size − 1] and flags in {0, 1}. The bounds are part of the observation space saved with a model, so a model loads only into the same grid size and package count.

Reward Structure

  • Delivery bonus: +10
  • Pickup reward: +1
  • Distance reduction bonus: +0.1 for a move that reduces the distance to the nearest undelivered package
  • Distance penalty: -0.01 multiplied by that distance, after each move
  • Step cost: -0.05 default, every step, including actions that change nothing

The two distance terms apply only to move actions taken while not carrying a package.

Environment Details

  • Grid-world delivery environment with configurable dimensions and package count.
  • The agent starts at the top-left cell; packages are placed at random inside the border.
  • The delivery zone is always the bottom-right cell; it is not configurable.
  • An episode terminates when every package is delivered and is truncated at max steps.
  • Dashboard and visualizer provide real-time trajectory and reward diagnostics.
