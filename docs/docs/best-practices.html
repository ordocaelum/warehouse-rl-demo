Getting Started

  • Start with default dashboard parameters and one-package task.
  • Observe at least 5-10 minutes before judging progress.
  • Prioritize moving-average trend over per-episode volatility.

Curriculum Learning

Stage 1 · 8x8, 1 package

Train for 100k timesteps. Save checkpoint when average reward stays above +6.

Stage 2 · 10x10, 2 packages

Train for 150k timesteps. Track multi-objective routing improvements.

Stage 3 · 12x12, 3 packages

Train for 200k timesteps. Expect noisier curve with gradual upward trend.

Stage 4 · 15x15, 3-5 packages

Train for 300k+ timesteps. Evaluate stability and delivery consistency.

Debugging Checklist

Observation spaces do not match

Loaded checkpoint was trained with a different package count. Match configuration before loading.

Flat reward graph

Lower difficulty, increase timesteps, and verify training loop is actively running.

Low FPS during training

Reduce map size or package count, and close competing CPU-intensive applications.

Common Mistakes

Jumping to hard tasks too early

Begin with foundational settings and scale gradually.

Changing parameters mid-run

Reset stats and start a fresh session after parameter updates.

Expecting immediate convergence

Allow sufficient episodes before evaluating quality.

Ignoring moving average

Track trend line, not noisy episode spikes.
